🩺 Diabetic Retinopathy Detection Using CNNs

A deep learning-based web application designed to detect Diabetic Retinopathy from retinal fundus images using Convolutional Neural Networks (CNNs). The system assists in the early identification of diabetic eye disease, helping improve diagnosis and treatment outcomes.

🌟 Overview

Diabetic Retinopathy is a diabetes-related eye disease that can lead to vision loss if not detected early. This project uses a trained CNN model to analyze retinal images and predict the presence of diabetic retinopathy automatically.

🎮 How It Works

1. Upload a retinal fundus image.

2. The image is preprocessed and resized.

3. The CNN model analyzes the image.

4. The system predicts whether Diabetic Retinopathy is present.

5. The prediction result is displayed to the user.
